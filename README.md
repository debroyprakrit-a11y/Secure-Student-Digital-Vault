# Secure Student Digital Vault
## Project description
It is a command line based application which I have made
to manage student information securely.
This application provides password:protected system and
allows user to add,view,search and manage students records.
## Features
-Password protected login
-Adding student records
-Viewing student details using ID
-Viewing details of all students
-Logout option
##Technologies used
-Python
-PyCharm
## Project Purpose
The project demonstrates Python programming concepts such as
-Variables
-Input and Output
-Loops and Conditional statements
-Lists
-Dictionaries
-Searching
## Requirements
-Python 
-Pycharm or Python IDE
## How to Run
1.Open the project in PyCharm
2.Open 'main.py'
3.Run the Python program
4.Enter the password  when asked
5.Select any option from main menu.
## Student Information
It consists of following information for each student:
-Student ID
-Student Name
-Course
-Email
-Marks
## Login System
This program allows a maximum of three password attempts before access is denied
## Main menu
1.Add student
2.View student
3.View all students
4.Student statistics
5.Logout
