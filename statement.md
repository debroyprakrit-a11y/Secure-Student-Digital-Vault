# Project statement

## Problem Statement
My project provides a simple command-line system to manage student information.
It allows a users to add,view,search and manage student records through a 'password
protected' system.My project will reduce the time and difficulty which a person may 
face when he/she try to manage the student information manually.

## Scope of the Project
The project is designed to provide basic student record management through a command
line interface.
My project includes this features:
-Secure login using password
-Adding student records
-Viewing individual student details
-Viewing all student records
-Viewing student statistics
-Logging out of system

## Target Users
The project is intended for:
-Students who are learning Python Programming
-Teachers managing basic student information
-Beginner who want to understand how a command line interface works

## High Level Features
-Password-protected login
-Student record management
-Student search using ID
-Displaying of all student records
-Student statistics
-Logout feature
